Full FITS · Local Preview

A standalone experimental viewer that reads SPHEREx FITS images on your own device. It never uploads your file to Render or Google Drive and does not modify the main Artemisos viewer.

1 · Get an observation

Download the team's public FITS file using the Google Drive link below, then open it locally.

Open the sample SPHEREx FITS on Google Drive

2 · Use an earlier cached observation

Files previously stored on the Drive diagnostics page are also available here.

3 · Scientific image preview

Choose an uncompressed FITS file and click Preview.

Color scaling is only for visual inspection. This preview does not reproject images onto common coordinates, remove contamination, measure flux, or replace calibrated scientific analysis. Gzip and compressed-image FITS are not supported in this proof of concept.
